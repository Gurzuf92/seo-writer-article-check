Command and JSON reference

This reference describes Article Check 0.1.0. The implementation is in article_check.py.

Command line

python article_check.py FILE [--json] [--fail-on {error,warning,never}]
Argument Behaviour
FILE One local UTF-8 or UTF-8-BOM HTML file, at most 5 MiB
--json Print the report as machine-readable JSON
--fail-on error Default: exit 1 when an error finding exists
--fail-on warning Exit 1 for warning or error findings
--fail-on never Exit 0 after a successful inspection, preserving findings

Exit 2 means invalid arguments, an unreadable input or an input beyond the size limit. --fail-on never does not suppress argument and file-reading failures.

JSON report fields

Field Meaning
version Utility version
title Whitespace-normalized document title
h1_count, headings Visible heading inventory; headings contain level and text
words, text_scope Heuristic word count; article text is preferred when available
canonicals Canonical href values found in the export
links_found, images_found Link and image counts
json_ld Block count, discovered types and invalid block details
counts Finding counts by severity; absent severities need to be read as zero
findings Objects with severity, code and message
limits Reminder of the local parser's scope

Consumers should tolerate additional fields in future versions. JSON-LD type discovery follows top-level objects, arrays and @graph; it is not a complete vocabulary validator.

Finding codes

Code Severity Review action
missing_title warning Check the final CMS title
h1_count warning Review zero or multiple visible H1 elements
canonical_count warning Review zero or multiple canonical elements
relative_canonical warning Verify the absolute public page URL
invalid_json_ld error Fix JSON syntax and ensure the value is an object or array
no_json_ld info Check whether the CMS adds markup; markup is not a citation requirement
active_link warning Review javascript:, data: or vbscript: links
missing_alt warning Add appropriate alt attributes; empty alt is valid for decorative images
no_text warning Check the export; the parser does not execute JavaScript

The script hides obvious inline-hidden content and excludes scripts, styles and templates from static text. External CSS and malformed HTML can produce differences from a browser.

Python use

from article_check import inspect_html

report = inspect_html("<html><title>Draft</title><article><h1>Draft</h1><p>Hello.</p></article></html>")
errors = report["counts"].get("error", 0)
for finding in report["findings"]:
    print(finding["severity"], finding["code"])

inspect_html returns a dictionary and does not apply the CLI file-size guard. Read and bound external input in your caller when embedding it. This utility is separate from the commercial SEO Writer publishing service.
