Troubleshooting a preflight report

Use this guide for Article Check 0.1.0. Start with a small local reproduction, not a private production export shared in a public issue.

The command exits with code 2

Check the path, quote paths containing spaces, confirm the file is readable and saved as UTF-8, and keep it below 5 MiB. A website URL is not a supported input. Export the document first.

A CMS export has no title or canonical

That can be expected when the export contains only article-body HTML. Review what the CMS adds in its preview and public page. The tool reports an incomplete local document; it does not know the eventual permalink or your SEO plugin's configuration.

An image is decorative

An explicitly empty alt="" is accepted. A missing alt attribute is reported. Decide the correct text based on the image's role; do not insert a keyword list solely to silence the warning.

JSON-LD parses but the information is wrong

The tool checks JSON syntax and basic object/array shape. It does not validate required Schema.org properties, prove factual claims or check agreement with the visible page. Use the Schema.org validator separately and review the actual page content.

A command passes but the live page looks broken

The local parser does not run the theme, CMS plugins, JavaScript or external CSS. Check the rendered page after import. Plugins can add, remove or change headings, links, media and metadata.

I need a non-blocking report in automation

python article_check.py export.html --json --fail-on never

The report still contains findings. File-reading and argument failures still exit 2. Use this mode for reporting rather than assuming it certifies the page for publication.

Does this improve GEO or guarantee indexing?

The report does not measure search visibility or citations. Google's AI features guidance describes requirements for its own search features. Measure search inclusion and observed citations separately.

Report a bug safely

Include the Python version, the exact command, the expected result and a minimal invented HTML example in the GitHub issue tracker. Remove private drafts, account details and credentials. The utility is maintained alongside SEO Writer, while its source and these docs are MIT-licensed and usable on their own.
