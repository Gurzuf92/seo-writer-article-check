SEO Writer Article Check: hands-on documentation

Version 0.1.0 · Python 3.10+ · MIT license · Updated 26 November 2026

Article Check reads one local HTML export and produces a publishing preflight report. It uses the Python standard library, runs offline and accepts HTML from any editor. You do not need an account, an API key or the SEO Writer service to use it.

Maintained alongside SEO Writer, a separate service for preparing articles and publishing them to a CMS. The source of this utility is public on GitHub.

Install and run the synthetic example

git clone https://github.com/Gurzuf92/seo-writer-article-check.git
cd seo-writer-article-check
python article_check.py examples/article.html

On Windows, use py instead of python if the Python launcher is your usual command. The example is invented editorial material on example.org, not a customer result.

Inspect your own export

Save the article as a local UTF-8 HTML file. From the repository directory run:

python article_check.py "path/to/article.html" --json

The input limit is 5 MiB. The command reads that file; it does not download a URL, render JavaScript, upload a draft or write to your CMS.

Use a stricter editorial gate

python article_check.py "path/to/article.html" --json --fail-on warning

This makes warnings fail the command as well as errors. Fix or consciously accept each finding before using the result in a publishing workflow. A missing canonical in an export may be normal when the CMS creates it later; verify the live page rather than inserting a guessed URL.

After the local check

  1. Check facts, sources and permissions for images.
  2. Import the article into a CMS draft and review headings, links and media.
  3. Inspect the rendered preview on wide and narrow screens.
  4. After an authorized publication, open the public URL without signing in and check its actual metadata.

An empty findings list means these local heuristics found no issue. It is not a content-quality rating, security audit, full Schema.org validation, indexing result or prediction of AI citations.

Reproduce the project's existing checks

python -m unittest discover -s tests -v

See the command and JSON reference for output fields and the troubleshooting guide for interpreting findings. The existing Russian editorial walkthrough remains available on GitHub Pages.
