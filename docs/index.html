Проверьте HTML до публикации

Article Check читает локальный HTML-файл и помогает заметить сломанную JSON-LD разметку, пропущенный заголовок, изображения без alt и подозрительные ссылки. Python, стандартная библиотека, один файл.

Проект команды SEO Writer — сервиса подготовки статей и публикации в CMS. Утилита работает с экспортом из любого редактора.

Быстрый запуск

Нужен Python 3.10 или новее. Аккаунт, ключ API и установка пакетов не требуются.

git clone https://github.com/Gurzuf92/seo-writer-article-check.git
cd seo-writer-article-check
python article_check.py examples/article.html
python article_check.py export.html --json

В Windows можно использовать команду py вместо python. Файл должен быть в UTF-8 и занимать не больше 5 МиБ. В репозитории есть учебный HTML-пример с вымышленным адресом example.org.

Как читать результат

Article Check 1.0.0: How to review an AI-assisted article before publishing
Words: …; H1: 1; JSON-LD blocks: 1

Количество слов — справочная величина. Утилита не задаёт оптимальную длину статьи. Полный JSON содержит заголовки, типы разметки и список замечаний.

error означает некорректный JSON-LD. warning предлагает проверить элемент вручную. info сообщает о контексте экспорта. По умолчанию код 1 возвращается только при ошибке; режим --fail-on warning учитывает и предупреждения. Код 2 означает ошибку входного файла или аргументов.

Что проверяется

ЭлементЧто означает замечание
Title и H1Проверьте название и видимый заголовок конечной страницы. CMS может добавлять их отдельно от текста.
Текст и подзаголовкиИнвентарь статического HTML. При наличии article считается текст статьи, а не меню.
CanonicalПроверьте один абсолютный адрес основной страницы. В экспорте редактора метаданных может не быть.
JSON-LDПроверяются синтаксис JSON и форма объекта или массива. Типы перечисляются для обычных блоков и @graph.
ИзображенияОтсутствующий alt отмечается. Пустой alt допустим у декоративной картинки.
СсылкиСхемы javascript:, data: и vbscript: требуют ручного просмотра. Доступность URL не проверяется.

Проверить воспроизводимые сценарии: python -m unittest discover -s tests -v. Исходники, учебный пример, история изменений и MIT-лицензия находятся в репозитории.

Редакторский чек-лист после проверки

  1. Один вопрос. Читатель понимает, какую задачу решает статья и кому подходит ответ.
  2. Проверяемые факты. Цены, ограничения и названия функций сверены с первоисточником. Учебный пример обозначен как учебный.
  3. Самостоятельный ответ. Главный раздел можно понять без чтения нескольких предыдущих экранов. Есть условия и ограничения.
  4. Рабочие ссылки и медиа. Ссылки ведут на нужные страницы; права на изображения понятны; содержательные картинки имеют подходящий alt.
  5. Разметка соответствует тексту. Article описывает статью, FAQ — реальные вопросы и ответы, HowTo — существующие шаги. Не добавляйте блок ради количества типов.
  6. Предпросмотр в CMS. Заголовки, таблицы, ссылки, изображения и мобильная версия сохраняются после импорта.
  7. Живая страница. После публикации проверьте итоговый адрес, статус, видимый текст и разметку ещё раз: шаблон и плагины могут изменить экспорт.

В процессе работы с SEO Writer утилита полезна между редактурой и публикацией: экспортируйте HTML, разберите замечания, затем проверьте предпросмотр. Подключение SEO Writer к WordPress описано на сайте сервиса.

Что инструмент не измеряет

Article Check не делает сетевых запросов, не исполняет JavaScript и не передаёт текст третьим лицам. Он не проверяет индексирование, сервер, внешние CSS, полноту Schema.org, достоверность текста или вероятность цитирования в ответах ИИ.

Google не требует специальной AI-разметки для участия в своих ИИ-функциях. Подготовка контента и техническая корректность не гарантируют ни индексирование, ни цитирование.

Синтаксически правильный JSON может содержать неверные свойства или описывать отсутствующий на странице контент. Для проверки словаря используйте отдельный валидатор, а содержание сверяйте вручную.
